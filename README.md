# INSEQ Skills

在你的 Agent 中使用 INSEQ 的 82 项能力：76 个用户入口、6 项内部能力。涵盖内容研究、策划、制作、复盘与画像，成果保存到同一 INSEQ 账号。

首次使用时登录 INSEQ 并同意连接，之后直接在当前对话提出需求。

- 帮我提取这个视频的文案。
- 分析这个账号，并给出新的选题方向。
- 结合我的画像，创作三条口播脚本。
