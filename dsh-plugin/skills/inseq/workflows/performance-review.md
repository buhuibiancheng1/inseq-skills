# 数据与运营复盘

使用[完整功能目录](../references/catalog.md)中的数据报告、ROI、评论洞察、内容复盘、数据追踪、互动潜力评分、内容效果分析、月度复盘及策略迭代能力。按用户所需输出定位对应技能，不默认一次执行全部复盘功能。

优先读取用户明确项目中的实际记录或用户本次提供的数据，使用公开工具定义提交。所需时间范围、指标或来源尚缺时只询问对应缺项；无数据不能生成虚构业绩、收益或平台内部指标。

区分真实数据、样本观察、预测评分与行动建议；评论样本不能代表完整粉丝群体，互动表现不能直接证明平台推荐原因。结论保留来源与适用范围。图表、报告页和文件必须取得实际产物后才能交付。

服务要求 Agent 完成分析时，依据真实资料完成本次要求，并通过返回的保存入口记录成果。当前对话交付完整报告，后续讨论和续改沿用原资料及最新版本，不让用户前往项目查看全文。
