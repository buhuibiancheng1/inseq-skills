# 资料与通用能力

使用[完整功能目录](../references/catalog.md)定位行业情报、RSS、内容日历、作品记录、账号查询、素材管理、模板库与批量处理。画像创建和编辑另见[画像与成果](project-management.md)。

通过 `inseq_search_skills`、`inseq_get_skill` 读取对应公开操作，再由 `inseq_run_skill` 按实际参数执行。只处理用户指定范围，读取当前项目真实资料；编号、现有记录和版本来自服务回执，不能编造。不要把查询账号当作创建画像。

订阅和行业资料保留实际来源及时间；日历保留原有安排与用户编辑。更新记录先读取当前版本，删除或其他不可逆操作遵循用户明确授权和服务已有保护，不因自然语言自动匹配技能而扩大修改范围。

模板和成果在用户获授权的项目范围内使用，批量处理逐项报告真实状态并保留失败项。云端后台运行与宿主实际能力分别说明，不把一次读取或保存称作持续监控已启用。

查找、选择、管理和续改都在当前对话中完成，文件使用实际附件或本次只读链接交付，不能以管理页面入口代替所需内容。
