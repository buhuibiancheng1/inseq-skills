# 内容创作与改写

根据用户要求创作选题、口播脚本、文案或图文。用户指定画像时先读取该画像及相关资料，已有明确选择直接沿用，不擅自使用别的项目。

选题与脚本通过用途检索对应技能，按公开参数调用 `inseq_run_skill`。根据实际回执完成当前 Agent 承担的文字创作或读取云端结果，用 `inseq_complete_skill` 或 `inseq_save_artifact` 保存实际成稿。没有资料支持的经营目标、产品承诺或数据不得写成既有事实。

文案改写使用 `inseq_rewrite_copy`，先确认本次依据：基于一份已保存画像；重点结合该画像绑定的业务资料；或暂不选择画像，直接描述要求。前两项关联具体画像。已提供选择不重复询问，业务资料绑定到所选画像。单纯提取原文不进入此选择。

用户要求全新选题时，结果应说明新的观众问题、与采样题材的实质区别、首条内容和适用条件；不能把旧作品续写、答疑或换对象当作全新方向。对旧内容的修改建议单独呈现。

图文、图片、视频或音频任务使用实际可用的服务。只在取得真实文件后称已完成，按[工具参考](../references/tools.md)读取和交付。每次视频生成均先取得本次报价并等待用户明确授权。

当前对话交付用户要求的完整成稿和实际文件；用户继续修改时读取最新版本，保护人工修改和原来源，不以“已保存，请前往项目查看”结束任务。
