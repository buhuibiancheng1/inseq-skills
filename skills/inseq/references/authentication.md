# 连接与授权

服务地址为 `https://inseq.zhujunyue.com/mcp`，传输为 Streamable HTTP，账号通过 OAuth 网页授权。

首次连接时使用宿主提供的授权入口，由用户在 INSEQ 网页登录、核对访问权限并确认。账号密码只在网页输入，不在聊天中索取密码、Token、Cookie 或 API Key，不读取其他应用的会话。

授权成功后提示用户手动切回原 Agent 对话，再实际调用只读工具确认连接。不要自行唤起应用协议、自动聚焦或关闭授权页。已有有效授权直接复用，更新 Skill 不要求重新登录。

授权过期或被撤销时，通过原连接器重新发起网页授权。网络故障、工具未加载或某项服务不可用，分别说明实际状态，不一律要求重新登录。不替用户操作登录授权界面，也不为了验证连接提交真实业务任务。
