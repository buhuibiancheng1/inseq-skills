# 结果卡片

有账号或作品列表的任务，必须在外部 Agent 当前对话的结果中呈现实际交互卡片，不能只描述卡片或输出纯文字表格。

使用服务返回的 `visualization`：支持 MCP Apps 时调用 `inseq_preview_results` 展示原任务；没有自动显示时也应调用一次。否则用宿主实际提供的交互网页／应用工具呈现 `visualization.html`，保留真实数据与交互。宿主确实不支持这两种方式时明确说明本次未显示卡片，并交付当前可用的媒体预览和附件；不能宣称已经显示，更不能让用户去 INSEQ 项目查看。

- 账号主页：头像、昵称、简介、实际账号统计在上方，下方显示作品、互动数据、原作入口与详情。
- 行业／同城／热点：以候选作品列表为主，显示封面、作者、平台、发布时间、互动数据和原作入口。
- 低粉爆款：作者粉丝量与作品表现并列，方便比较账号体量和单篇表现；不能把其他样本的指标补到当前作品。

同类作品行固定尺寸，长标题限行、详情展开，列表在固定外框内连续滚动，不擅自改为分页。缺失字段连同标签隐藏，真实 0 保留，不编造头像、封面、时长或互动量。

点击详情使用本次实际视频只读链接预览；仅有原作品链接时保留原作入口，不能把网页地址伪装成视频文件。链接过期时刷新原任务卡片，不重新采集或重新分析。卡片可预览不等于 Agent 已读取声画；分析仍需实际证据。

公开卡片和对话只展示用户需要的结果，不展示供应商、内部流程或配置。完整正文、后续选择与续改继续在当前对话完成。
