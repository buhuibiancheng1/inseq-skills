# 分析指定作品

具体作品分析对应 03「对标作品分析」（`skill-competitor-analysis`）。主页分析使用[对标账号分析](account-diagnosis.md)。

使用用户指定的作品链接或已提供素材，复用当前任务来源。通过 `inseq_get_skill` 获取本项公开输入定义，再以 `inseq_run_skill` 提交本次要求；项目与素材使用真实已返回的标识，缺少必要上下文时只询问该缺项，不创建虚假记录。

来源准备好后，按回执用 `inseq_get_asset` 读取原视频或图片。当前 Agent 必须实际读取视频声音和画面；用真实作品和原片时间支持结论。无法读取完整声画时说明实际覆盖，不能仅凭标题、封面、转写或高互动数字声称完成视频分析或证明走红原因。

使用 `inseq_complete_media_work` 保存实际完成的报告及覆盖信息，在当前对话交付完整正文和可查看来源。保留用户后续修改；继续追问时优先复用原来源和报告。
